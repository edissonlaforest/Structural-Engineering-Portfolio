# RC Seismic Retrofit

## Overview

Structural assessment and rehabilitation of reinforced-concrete structures with emphasis on seismic performance, demand-to-capacity relationships, drift control, and practical retrofit solutions.

## Engineering Scope

- Existing structural assessment
- Structural modeling
- Seismic demand evaluation
- Drift evaluation
- Member capacity assessment
- Retrofit alternatives
- Strengthening design
- Constructability assessment
- Cost and risk considerations

## Software & Standards

**Software:** ETABS · OpenSees/OpenSeesPy · Python

**Standards:** ACI 318 · ASCE 7 · IBC
