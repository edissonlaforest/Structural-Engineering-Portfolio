# Structural Assessment & Inspection

## Overview

Field-oriented structural assessment focused on identifying defects, deterioration, structural risks, and practical rehabilitation strategies.

## Engineering Scope

- Visual structural inspection
- Defect identification
- Concrete condition assessment
- Reinforcement condition review
- Crack assessment
- Structural section verification
- Load-path evaluation
- Preliminary structural diagnosis
- Rehabilitation recommendations
- Technical reporting

## Typical Investigation Methods

- Visual inspection
- Schmidt hammer testing
- Reinforcement detection
- Concrete cover measurement
- Structural measurements
- Engineering analysis
